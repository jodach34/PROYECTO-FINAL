# Contacto

Si representas un comedor, quieres donar, deseas ser voluntario o tienes una idea para la red, puedes usar el formulario de contacto. El formulario está preparado visualmente, pero el envío de mensajes todavía no está conectado a un servicio.

## Qué puedes escribirnos

El formulario permite indicar tu nombre, correo, motivo y mensaje. Los motivos disponibles son: represento un comedor, quiero donar alimentos, quiero ser voluntario, propongo una alianza u otro tema. No incluyas datos sensibles de personas beneficiarias.

## Estado actual del formulario

Actualmente no existe un endpoint que reciba los mensajes. Al enviar el formulario la interfaz muestra un aviso de que el envío está pendiente; el texto no se envía ni se guarda. No se simula una confirmación falsa.

## Otras formas de participar

Puedes explorar el directorio de comedores para conocer el estado de la red y las fichas públicas. Si ya donaste, puedes consultar el estado con tu código de seguimiento. Para registrar una donación de insumos, usa el formulario de donaciones.

## Datos y privacidad

La información que escribirías en el formulario se usaría únicamente para responder a tu mensaje, según la política de privacidad. Mientras el envío no esté habilitado, no se almacena ningún dato desde esa pantalla.
